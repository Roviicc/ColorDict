### PopUp Dictionary has a new look
- **New name:** PopUp Dictionary.
- **New icon:** a definition popping up from a highlighted word. On Android 13 and later it also follows your themed-icon colors.
- **New in-app icons** from the Hugeicons set, for a lighter, more consistent look.

Nothing else changes: your saved words, connotations and API key are kept.

### Install
Download **popup-dictionary-debug.apk** below. It installs as an update over any v2 release. (Older download links still work.)
