A complete rebuild: a clean, offline English dictionary with a quick-lookup popup, and connotations from Claude when you want them.

### What's new
- **Built-in dictionary:** about 150,000 English words with pronunciation, numbered meanings, examples, synonyms and opposites. Instant, offline and free (Open English WordNet 2024, CMU Pronouncing Dictionary).
- **Check connotation:** tap it on any word and Claude explains how the word feels to people (tone, a short explanation, descriptors and when it can come across differently). It's saved with the word, so next time it's already there. Uses your own Anthropic API key (Settings → API key).
- **Redesigned popup:** select text in any app and tap **Define** to get a bottom sheet with the meaning; swipe down to close. E-book readers that use the ColorDict lookup intent keep working.
- **Smarter search:** suggestions as you type, inflected forms find their base word (geese → goose, ran → run), and typos get "Did you mean" suggestions.
- **Recent and Saved** word lists, copy, share, text-to-speech, and light and dark themes.

### Install
Download **colordict-debug.apk** below and open it on your phone (Android 8.0 or newer). The first lookup takes a few seconds while the dictionary unpacks.

If an earlier ColorDict is installed and Android says the app isn't compatible or the package conflicts, uninstall the old version first. That's a one-time step: from this version on, every release is signed with the same key and installs as an update.

The **release-unsigned** APK is for people who want to sign it with their own key.
