### What's new
- **Popup expands as you scroll:** the quick-lookup popup opens short with the top meanings. Scroll or drag up and it grows to nearly full screen with the full entry, still over what you're reading. Drag the handle down to shrink it, and again to close.
- **"See full entry" moved** from a sticky button to a link at the end of the meanings.
- **Words not in the built-in dictionary:** tap **Look up with Claude** to get the meaning and connotation in one go (slang, new words, names, abbreviations). The answer is saved, so the word opens instantly next time, labelled as written by Claude.

### Install
Download **colordict-debug.apk** below and open it. It installs as an update over v2.0.0 and keeps your saved words and API key.
