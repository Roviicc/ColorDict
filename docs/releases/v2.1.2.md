### New name: Pop Dictionary
ColorDict is now **Pop Dictionary**, so the home-screen icon and the app's name change. Nothing else changes: your saved words, connotations and API key are kept, and e-book readers that use the ColorDict lookup intent still open the popup.

### Install
Download **pop-dictionary-debug.apk** below. It installs as an update over any v2 release. (The old **colordict-debug.apk** link still works and is the same app.)
